# 🎯 Smart Portfolio Analyzer

A smart, AI-enhanced personal portfolio website that not only showcases your projects but also evaluates and improves them! Built using **HTML**, **CSS**, and **JavaScript**, this application integrates AI to provide real-time, constructive feedback on your portfolio content, design, and clarity.

---

## 🚀 Features

- 🖼️ **Portfolio Showcase** – Upload and display your projects using interactive cards.
- 🤖 **AI Project Analysis** – Receive actionable feedback on your project descriptions, visuals, or code links.
- 🧠 **Intelligent Ratings** – Evaluate projects based on clarity, design, technical depth, and impact.
- 🎨 **Responsive UI** – Works seamlessly across desktop, tablet, and mobile devices.
- 🌗 **Light/Dark Mode** – Enhance viewing experience with theme toggle.
- 📂 **Support for Images & Links** – Upload screenshots or paste GitHub/Dribbble links for AI analysis.

---

## 🛠️ Tech Stack

- **HTML5** – Markup and structure
- **CSS3 (Flexbox & Grid)** – Styling and layout
- **JavaScript (Vanilla)** – Interactivity and logic
- **[OpenAI API](https://platform.openai.com/)** – AI-based feedback generation
